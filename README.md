# dbtodbc

Reads rows from a database and writes them out as client `.dbc` files (plus CSV copies for inspection). The goal is to streamline generating client DBCs directly from DB data, instead of hand-editing `.dbc` files in a DBC editor.

`src/vendor` contains DBC loading/definition headers taken from [AzerothCore](https://github.com/azerothcore/azerothcore-wotlk), used here to keep the DBC file format handling compatible with the client.

## Download

Prebuilt Windows binaries are published on the [GitHub Releases page](https://github.com/JSlomian/dbtodbc/releases) for each tagged version. `dbtodbc.exe` is statically linked against the MariaDB client and the MinGW runtime, so no MSYS2/MinGW install is required — just unzip the release archive and run it. A handful of `libcurl` runtime DLLs are bundled alongside the exe in the zip (curl is a transitive dependency of the MariaDB client that can't be statically linked); keep them in the same folder as `dbtodbc.exe`.

## Configuration

`dbtodbc` reads a plain key=value config file at runtime. It is **not** generated by CMake or the build — you must create it yourself before running the executable.

By default the program looks for `dbtodbc.conf` in the current working directory. You can point it at a different file by passing the path as the first CLI argument:

```
dbtodbc.exe path\to\dbtodbc.conf
```

Lines starting with `#` or `;` are treated as comments; values may optionally be wrapped in single or double quotes.

### Required keys

| Key | Description |
|---|---|
| `DB_USER` | Database username |
| `DB_NAME` | Database name |
| `DBC_SOURCE_DIR` | Directory containing input `.dbc` files |
| `OUTPUT_DBC_DIR` | Directory to write output `.dbc` files |
| `OUTPUT_CSV_DIR` | Directory to write output `.csv` files |

### Optional keys

| Key | Default | Description |
|---|---|---|
| `DB_PASSWORD` | (empty) | Database password |
| `DB_HOST` | (unset) | Database host |
| `DB_PORT` | (unset) | Database port |

### Example

```
DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=root
DB_PASSWORD=password
DB_NAME=acore_world
DBC_SOURCE_DIR=C:\path\to\azerothcore-wotlk\env\dist\data\dbc
OUTPUT_DBC_DIR=D:\path\to\client\Data\patch-5.MPQ\DBFilesClient
OUTPUT_CSV_DIR=output_csv
```

## Testing

`test/roundtrip_main.cpp` is a verification harness built as the `roundtrip_test` CMake target (alongside `dbtodbc`). It hand-builds a raw WDBC file in memory, round-trips it through `LoadDbcFile -> WriteDbcFile -> LoadDbcFile`, checks the loaded tables match, then writes it out a second time to confirm the writer is byte-for-byte idempotent.

It only depends on `DbcReader`/`DbcWriter`, so it builds without the MariaDB client library. Run it with:

```
cmake --build build --target roundtrip_test
build/roundtrip_test
```
